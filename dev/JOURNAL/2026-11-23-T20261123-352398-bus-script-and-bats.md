# T20261123-352398: Bus step 2: _bus/bus.sh and bats tests

Parent: T20261122-234265; spec: [cross-account-bus-spec.md](../docs/cross-account-bus-spec.md)

## Scope

- `_bus/bus.sh` with `send`, `deliver`, `watch`, `status`, `read`, `prune`; locks through `_session/lock.sh`, no `flock`
- Bash and tools present on macOS and Linux only; pin time with `NOW=`
- Bats: encode/decode, unknown fields, 4000-char cap, cursor and `recent_ids`, rotation at EOF, 4 writers concurrency, `kill -9` crashes, permission and second-session guards, injection sanitizing

## Solution

- `_bus/bus.sh` (`init`, `send`, `deliver`, `watch`, `status`, `read`, `prune`) plus `_bus/README.md`; locks from `_session/lock.sh`, no `flock`; bash 3.2 and 5, macOS and Linux
- Delivery: cursor saved with the new ids first and the offset after the output, so a kill in between repeats nothing; rotation only when the cursor is at end of file
- Trust: sanitize, escape `<`, quote each line, wrap with the "not your user" label; permissions and filesystem guards; one live session per name (a new session id under the same process is not a second session)

## Design decisions

- Config shape (no home-to-work knob was specified): `<profile>/ccxp-bus/config.json` with `name`, `label`, `retention_days`, `allow_from`; absent `allow_from` allows every registered agent
- `NOW=` pins the clock; `BUS_TEST_CRASH` is the only test hook (`send-mid`, `deliver-after-inject`)
- The concurrency test defaults to 250 notes per writer to keep CI short; the spec's 1000 per writer was also run and passes (`BUS_STRESS_NOTES=1000`)
