# T20261123-381381: Review existing decisions when a new one is logged

## Problem

- **Type**: feature
- Owner (d146): "when we log a new 'decision', in our `ledger.sh decision`, please make sure we review existing decisions, clean up the stale ones, and consolidate existing decisions, and raise concerns if we have contradicting decisions."
- The log only grew: nothing pointed at overlapping, outdated or conflicting standing rules.

## Design

- `decision add` and `decision supersede` print the new `d<n>` alone on stdout (callers that read it keep working) and a review block on stderr; no block when no other decision is active.
- Checks are deterministic and token-free (jq): overlap = at least 2 shared stopword-filtered words (same scope or global); stale = gone `--context` file, a past date next to a "retire this decision/once/after/until" phrase, or older than `CCXP_DECISIONS_MAX_AGE_DAYS` (90) with no `source`; contradiction = opposite polarity or a different number for the same unit word between overlapping decisions. Flags only, never decided.
- `decision review [--scope S] [--json]` runs the checks over all active decisions (overlap groups, stale, contradictions).
- Persona rule: relay the block to the owner; retire or consolidate only with the owner's approval. Persona trimmed to stay under its size guard.

## Test plan

- [x] `tests/ledger.bats`: block with a related decision, ref alone on stdout, supersede, no noise without others, gone context, past-date and age staleness, polarity and number contradictions, `review --json` shape and scope.
- [x] `tests/agent_pairing.bats`: persona rule present; size guard still passes.
