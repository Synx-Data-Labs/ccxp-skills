# T20261123-596451: Bus step 3: hooks.json entries

Parent: T20261122-234265; spec: [cross-account-bus-spec.md](../docs/cross-account-bus-spec.md)

## Scope

- `SessionStart` (`deliver --register`, async `watch`), `UserPromptSubmit` (`deliver`), `Stop` (async `watch`)
- Watcher timeout 28800 s, exit 0 a minute early
- Silent exit 0 on nothing to say or any failure; inert when the profile has no bus config

## Solution

- `hooks/hooks.json`: `SessionStart` (`startup|resume`) runs `bus.sh deliver --register` (5 s) and an async `asyncRewake` `bus.sh watch` (28800 s); `UserPromptSubmit` runs `bus.sh deliver` (5 s); `Stop` re-arms the async watcher. New entries come after the existing ones so earlier indexes do not move.
- `bus.sh` hook commands (`deliver`, `watch`, `status`) always exit 0 on nothing to say or any failure; only a wake from `watch` exits 2. The watcher gives up at 28740 s, a minute before the timeout.
- Inert when the profile has no `ccxp-bus/config.json`: no output, no files created.
